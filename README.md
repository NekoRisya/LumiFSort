# RimuFileSort / LumiFSort

This program only sorts messed up structures into known ones. Works for directories with classifiers.

> [!WARNING]
> It can mess up your structure and also doesn't support in-place sorting.

## Installation & Usage

```bash
git clone https://github.com/RimuEirnarn/LumiFSort
cd LumiFSort
python main.py /path/to/src /path/to/temp
mv /path/to/temp /path/to/src
```
